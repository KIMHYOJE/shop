# 🛒 Shop - 1학기 백엔드 스터디 기록

## 📝 소개
이 저장소는 1학년 1학기 동안 백엔드 개발을 처음 배우며 스터디한 코드와 개념들을 기록해 둔 공간입니다. 
이제 막 백엔드에 입문하는 학생의 시선에서, 기본적인 서버 구조를 이해하고 직접 코드를 작성하며 동작 원리를 익히는 데 초점을 맞췄습니다.

## 🛠 기술 스택 (Tech Stack)
- **Language:** Java
- **Framework:** Spring Boot
- **Database/ORM:** JPA (Java Persistence API)
- **Build Tool:** Gradle

## 📚 주요 스터디 내용
- **Spring Boot 기초:** 백엔드 프로젝트의 기본 구조와 환경 설정 방법 학습
- **JPA 및 데이터베이스 매핑:** Entity 클래스 정의 및 관계형 데이터베이스(RDB)와의 기본적인 매핑 이해
- **간단한 상품 등록, 조회 기능 구현 등**

## 💡 배운 점 & 느낀 점
- 복잡해 보이던 백엔드 프레임워크가 어떻게 동작하는지 전체적인 흐름을 이해하게 되었습니다.
- 처음 접하는 백엔드라 낯선 개념들이 많았지만, 내가 짠 코드대로 데이터가 저장되고 서버가 돌아가는 과정을 직접 확인하는 것이 정말 신기하고 재밌었습니다!
